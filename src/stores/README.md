# Dossier Stores Zustand (`src/stores/`)

Conformément aux règles du projet ([`00_global.md`](file:///home/maximilien/Projets/CDA_IA/grimoire_tactics/.agent/rules/00_global.md)), tous les stores d'état Zustand doivent résider dans ce dossier sous forme de fichiers courts sans suffixe redondant (pas de `_store`).

Exemples de nommage :
- `collection.ts` : Store d'état pour la collection de cartes du joueur.
- `battle.ts` : Store d'état pour la composition d'équipe et le déroulement du combat.
- `gacha.ts` : Store d'état pour l'ouverture des packs et le tirage.
