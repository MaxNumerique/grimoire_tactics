# Dossier Centralisé des Tests (`tests/`)

Conformément aux règles du projet ([`04_qa_testing.md`](file:///home/maximilien/Projets/CDA_IA/grimoire_tactics/.agent/rules/04_qa_testing.md)), le dossier `tests/` contient exactement 3 sous-dossiers :

- `tests/unit/` : Tests unitaires (moteur de combat, calculs de dégâts, fonctions pures).
- `tests/integration/` : Tests d'intégration (API routes, Prisma DB, flux gacha).
- `tests/e2e/` : Tests de bout en bout de l'interface utilisateur.
